Datenschutzerklärung

Für die App Lumio (Android, Windows, Linux, Raspberry Pi) und diese Website · Stand: 19. Oktober 2026

Kurz gesagt: Lumio hat keine Benutzerkonten, keine Werbung und kein Tracking. Fotos, Videos und Einstellungen bleiben auf deinem Gerät. Der Entwickler erhält keine Fotos und keine personenbezogenen Daten von dir. Die einzige Verbindung ins Internet ist eine Abfrage bei GitHub, ob es eine neue Version gibt.

1. Verantwortlicher

Marcel Suffel
Kontakt: über die Issue-Seite des Projekts auf GitHub

2. Fotos, Videos und Einstellungen

Mit Lumio aufgenommene Fotos, Collagen, GIFs und Videobotschaften werden ausschließlich lokal auf dem Gerät gespeichert – auf Android im Ordner „Bilder/Lumio“, auf dem PC im gewählten Speicherordner (z. B. „Bilder\Lumio“ oder einem USB-Stick). Einstellungen wie Event-Name und PIN liegen ebenfalls nur lokal. Lumio überträgt diese Inhalte nicht an den Entwickler oder an Dritte. Löschen kannst du sie jederzeit in der Lumio-Galerie, in der Galerie-App oder im Dateimanager deines Geräts.

3. Berechtigungen der Android-App

  • Kamera – für Live-Bild und Fotos.
  • Mikrofon – nur für die Tonspur von Videobotschaften.
  • Fotos & Videos – damit die Galerie in Lumio auch Fotos früherer Installationen anzeigen kann.
  • USB – zum Anschluss von Kameras (z. B. Nikon) und Webcams.
  • Lokales Netzwerk / WLAN – um einen Fotodrucker (z. B. Canon Selphy) im eigenen WLAN zu finden. Gedruckt wird nur, wenn du oder deine Gäste auf „Drucken“ tippen; das Foto geht dann direkt an diesen Drucker im lokalen Netzwerk.
  • Internet – ausschließlich für die Update-Prüfung (Punkt 4).

4. Update-Prüfung bei GitHub

Lumio fragt beim Start und danach alle paar Stunden bei GitHub (api.github.com) nach, ob eine neuere Version veröffentlicht wurde. Dabei werden technisch notwendige Daten an GitHub übermittelt: deine IP-Adresse, Zeitpunkt der Anfrage und die Programmkennung „Lumio“ mit Versionsnummer. Es werden keine Fotos, Namen oder Geräte-IDs übertragen. GitHub ist ein Dienst der GitHub, Inc. (USA); es gilt die Datenschutzerklärung von GitHub. Rechtsgrundlage ist das berechtigte Interesse, dich auf Updates und Fehlerbehebungen hinzuweisen (Art. 6 Abs. 1 lit. f DSGVO). Ohne Internetverbindung funktioniert Lumio uneingeschränkt.

5. Diese Website

Diese Seite wird über GitHub Pages bereitgestellt. Beim Aufruf verarbeitet GitHub technisch notwendige Zugriffsdaten (z. B. IP-Adresse, Zeitpunkt, Browser), um die Seite auszuliefern und abzusichern. Die Startseite fragt zusätzlich bei api.github.com die aktuelle Versionsnummer ab. Es werden keine Cookies, keine Analyse-Tools und keine externen Schriftarten verwendet.

6. Google Play

Wenn du Lumio über Google Play installierst, verarbeitet Google dabei Daten nach seinen eigenen Bestimmungen (Datenschutzerklärung von Google). Der Entwickler erhält von Google nur zusammengefasste, anonyme Statistiken (z. B. Installationszahlen und Absturzberichte ohne Personenbezug).

7. Kinder

Lumio richtet sich nicht gezielt an Kinder und erhebt keine Daten von ihnen.

8. Deine Rechte

Du hast das Recht auf Auskunft, Berichtigung, Löschung und Einschränkung der Verarbeitung deiner Daten sowie ein Widerspruchsrecht gegen die Verarbeitung nach Art. 6 Abs. 1 lit. f DSGVO. Da der Entwickler über Lumio keine personenbezogenen Daten erhält, betreffen diese Rechte in der Praxis vor allem die Daten bei GitHub und Google, die du direkt dort geltend machen kannst. Außerdem kannst du dich bei einer Datenschutz-Aufsichtsbehörde beschweren.

9. Änderungen

Ändert sich die Funktionsweise von Lumio in Bezug auf Daten, wird diese Erklärung angepasst. Die jeweils aktuelle Fassung steht unter dieser Adresse.

Privacy Policy

For the Lumio app (Android, Windows, Linux, Raspberry Pi) and this website · Last updated: October 19, 2026

In short: Lumio has no user accounts, no ads and no tracking. Photos, videos and settings stay on your device. The developer receives no photos and no personal data from you. The only internet connection is a request to GitHub to check for a new version.

1. Controller

Marcel Suffel
Contact: via the project's issue page on GitHub

2. Photos, videos and settings

Photos, collages, GIFs and video messages taken with Lumio are stored only locally on the device – on Android in the "Pictures/Lumio" folder, on PCs in the chosen output folder. Settings such as the event name and PIN are stored locally as well. Lumio does not transmit this content to the developer or to third parties. You can delete it at any time in the Lumio gallery, your gallery app or file manager.

3. Android permissions

  • Camera – for the live view and photos.
  • Microphone – only for the audio of video messages.
  • Photos & videos – so the Lumio gallery can show photos of earlier installations.
  • USB – to connect cameras (e.g. Nikon) and webcams.
  • Local network / Wi-Fi – to find a photo printer (e.g. Canon Selphy) in your own Wi-Fi. A photo is only printed when you or your guests tap "Print" and is sent directly to that printer on the local network.
  • Internet – only for the update check (section 4).

4. Update check with GitHub

At start and every few hours, Lumio asks GitHub (api.github.com) whether a newer version has been released. Technically required data is transmitted to GitHub: your IP address, the time of the request and the program identifier "Lumio" with its version number. No photos, names or device IDs are transmitted. GitHub is a service of GitHub, Inc. (USA); the GitHub Privacy Statement applies. Legal basis is the legitimate interest in informing you about updates and bug fixes (Art. 6(1)(f) GDPR). Lumio works fully without an internet connection.

5. This website

This site is hosted on GitHub Pages. When you visit it, GitHub processes technically required access data (e.g. IP address, time, browser) to deliver and secure the site. The start page additionally requests the current version number from api.github.com. No cookies, analytics tools or external fonts are used.

6. Google Play

If you install Lumio from Google Play, Google processes data according to its own terms (Google Privacy Policy). The developer only receives aggregated, anonymous statistics from Google (e.g. install counts and crash reports without personal reference).

7. Children

Lumio is not specifically directed at children and does not collect data from them.

8. Your rights

You have the right to access, rectification, erasure and restriction of processing of your data, and the right to object to processing based on Art. 6(1)(f) GDPR. As the developer does not receive personal data through Lumio, these rights mainly concern data held by GitHub and Google, which you can exercise directly with them. You may also lodge a complaint with a data protection supervisory authority.

9. Changes

If the way Lumio handles data changes, this policy will be updated. The current version is always available at this address.
